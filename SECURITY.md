# Security Policy

## Supported Versions

DreamNet Public Core is pre-1.0. Only the latest minor release receives security
fixes.

## Reporting

Do not open a public issue for a suspected vulnerability. Use GitHub's private
vulnerability reporting for this repository.

Do not include credentials, wallet keys, private user data, or proprietary
DreamNet configuration in reports or examples.

## Scope

This package validates public data contracts. It does not authenticate a
workload, sign transactions, execute tools, move funds, or authorize production
actions by itself.
